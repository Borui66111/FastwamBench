## 4. What the PSNR number does and does not measure

The displacement is applied **after** the clip was planned and is unobservable until the next
replan. A predictor whose future was generated before that exogenous change must disagree with
the realized rollout even if its learned dynamics are perfect. The −4.4 dB therefore measures
**counterfactual forecast invalidation under an unannounced intervention**.

| # | quantity | measured here? |
|---|---|---|
| i | pre-intervention prediction fidelity | yes — lag-0 delta is 0.00 dB by construction; the control lookahead curve is the no-intervention baseline |
| ii | induced surprise after the change | yes — the lag-4 delta |
| iii | mismatch detection | no — nothing in this run reads PSNR to trigger a replan |
| iv | post-replan prediction / action quality | no — the scored clips were planned before the strike |
| v | task recovery | no — that is the task-success arm (§1) and Gates 13B–13D |

`stale_action_steps == H` is a runner contract (§2), not a learned property.

Note on the metric: PSNR is a log measure, so dB differences are reported next to ΔMSE in
8-bit units² (`MSE = 255²/10^(PSNR/10)`, the harness convention at
`eval_libero_single.py:_clip_frame_psnr`). A last-frame/persistence predictor is **not**
included: the bundle keeps per-frame PSNR, not frames, so it cannot be computed here. That
remains an open item (Gate 14B).

## 5. Validity checks

| check | result | detail |
|---|---|---|
| pair counts: every (task,H,seed) has both arms on identical init states | PASS | 80 pairs; problems: none |
| pre-intervention equality: control == disturb action-by-action before step 40 | PASS | 160 step-pairs compared; max |L1| = 0 |
| stale contract: control executes 0 stale actions, disturb executes exactly H | PASS | 0 violations |
| PSNR pairing: both arms present on identical (seed, init_state) for every H | PASS | problems: none |

Pairing unit: **init state**, not episode. LIBERO loads `init_states[trial_idx]`, so episode
index *is* the init-state index; 2 seeds × 5 trials is 5 distinct init states observed under 2
RNG realizations, not 10 independent initial states. Confidence intervals therefore resample
init states (5 clusters), which is the honest unit.
