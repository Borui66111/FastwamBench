# FastBench Server Handoff

Start here:

1. Read `AGENTS.md`.
2. Read `WARM_START.md` end-to-end once.
3. Read `STATE.md`, `REQUIREMENTS.md`, `INTEGRATION_PLAN.md`.
4. Run `python -m unittest discover -s tests -v` before modifying generic FastBench logic.

This package contains the dependency-light FastBench prototype plus the project handoff needed to continue on a real GPU server.
